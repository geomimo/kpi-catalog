# KPI Catalog

A website that helps employees of a (fictional) multi-unit company find, understand and compare the KPIs their organization uses, and helps unit managers and data stewards keep those definitions consistent.

Group project for the course *Information Organization*.

## Why
- **New employees** don't know which KPIs matter to their unit or how each one is defined, so someone has to explain it every time.
- **Units miscommunicate:** the same KPI name means different things in different units, and different names often mean the same thing.

## What the site does
- **Browse and search** KPIs with facets: Org Unit, KPI Category (Balanced Scorecard), Measure Type, user tags, and an A–Z index.
- **Compare definitions** of the same KPI across units, with warnings where they diverge.
- **Controlled vocabulary** in SKOS (Turtle), downloadable.
- **ML auto-tagging** with sentence embeddings, plus detection of synonyms and conflicts.
- **Lineage and usage**: what each KPI is computed from, and which dashboards use it.
- **Roles** (log in as any seed user): Observers explore; Contributors and Curators write definitions with tag suggestions; Reviewers approve them; Curators and Admins validate ML tags and promote user tags into the vocabulary.

The full scope, personas, use cases and plan are in **[docs/PRD.md](docs/PRD.md)**.

## Setup
Requires [uv](https://docs.astral.sh/uv/) and Python 3.14.

```bash
uv sync
uv run jupyter lab exploration.ipynb   # explore the dataset
```

Build and run commands will be added as the app is implemented (see PRD §11).

## Data
The seed catalog (~105 KPI definitions for a fictional retail group with 8 divisions) is generated by a deterministic script, `kpigen`. The KPI text is real:
- [`kavish218/multi_domain_dataset`](https://huggingface.co/datasets/kavish218/multi_domain_dataset) on Hugging Face (rows that fit the company);
- dbt Labs [`jaffle-sl-template`](https://github.com/dbt-labs/jaffle-sl-template) (Semantic Layer metrics with formulas and lineage);
- a few hand-written conflict cases.

Neither external source declares a licence, so they are downloaded at pinned versions and not committed. Users, roles, reviews and dashboards are synthetic. See PRD §3.
